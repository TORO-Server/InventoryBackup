# InventoryBackup

プレイヤーのインベントリのアイテムが失われた場合、インベントリを復元するメッセージを表示する SpigotMC プラグイン

バージョン 1.19 以上で動作します。

## 復元の対象

復元の対象になるのは、次の場合だけです。保持するのはプレイヤーごとに最新の 1 件で、1 度復元するか、サーバーから退出すると消えます。

| 原因 | 復元できる人 |
|---|---|
| クリエイティブのインベントリの操作でアイテムがすべて消えた | 本人、管理者 |
| 本人が実行した `/clear` でアイテムがすべて消えた | 本人、管理者 |
| 他の人が実行した `/clear` でアイテムがすべて消えた | 管理者 |
| 死亡してインベントリが空になった | 管理者 |

アイテムを容器へ移したり、地面に捨てたりしたときは対象になりません。インベントリが空でないときは復元できません。

管理者が死亡時のインベントリを復元するときは、地面に落ちたアイテムが残っていないことを確認してください。

## コマンド

- `/restore <番号>`: 自分のインベントリを復元する (メッセージをクリックすると実行されます)
- `/restore player <プレイヤー名>`: オンラインのプレイヤーのインベントリを復元する

## 権限

| 権限 | 既定 | 内容 |
|---|---|---|
| `inventory_backup.restore` | op | 自分のインベントリを復元する |
| `inventory_backup.restore.others` | op | 管理者の権限。`inventory_backup.restore` を含む |
